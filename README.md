Monday, Reviewed in One Line — my entry, the one-line review of my own Monday:

> Would not recommend Monday. The commute took an hour, the standup took two, and my inbox scheduled a meeting about the meeting.

Why this line: it opens with the verdict itself, so it reads as a review from the first words, then escalates through three concrete details — an hour-long commute, a two-hour standup, and an inbox that scheduled a meeting about the meeting. The escalation is the joke's turn, it lands inside the line, and "Would not recommend Monday" is the line a reader repeats to a coworker the next morning. Considered and rejected: a "One star … 47 unread emails" variant (flatter opening, weaker closer) and a "Monday reviewed itself" variant (the coffee detail diluted the escalation).

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` for local testing), UTF-8, 127 characters, mode 0644.
